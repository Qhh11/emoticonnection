# 快速开始 - Gemini Live 实时语音

## 🚀 现在就试试！

### 第1步：获取 API Key

1. 访问：**https://aistudio.google.com/app/apikey**
2. 点击 "Create API Key"
3. 选择一个项目或创建新项目
4. 复制生成的 API Key

### 第2步：打开测试页面

访问：**http://localhost:8000/static/gemini_live_direct.html**

### 第3步：开始对话

1. 将 API Key 粘贴到输入框
2. 点击 "🎙️ 开始对话" 按钮
3. 允许浏览器使用麦克风
4. 看到 "✅ 已连接 - 开始说话吧！" 后，就可以说话了
5. AI 会实时回复你！

## ✨ 特性

- ✅ **真正的实时对话** - 毫秒级响应
- ✅ **持续对话** - 无限多轮，不会自动断开
- ✅ **语音活动检测** - AI 可以被随时打断
- ✅ **双向音频流** - 同时听和说
- ✅ **对话记录** - 实时显示转录文本

## 💡 使用技巧

### 持续对话

- 说完话后**直接继续说下一句**
- 不需要点击任何按钮
- AI 会在它说完后自动等待你的下一句话
- 想结束对话时点击 "停止" 按钮

### 打断 AI

- AI 说话时你也可以随时开口
- AI 会自动停止并听你说话
- 这是 Voice Activity Detection (VAD) 的功能

### 最佳体验

- 🎧 **使用耳机** - 避免回音导致AI自己被打断
- 🔇 **安静环境** - 减少背景噪音提高识别准确度
- 🎤 **清晰说话** - 麦克风距离适中，发音清晰

## 🔧 如果遇到问题

### 1. 连接失败

**症状**：点击开始后显示 "连接错误"

**解决办法**：
- 检查 API Key 是否正确
- 确保网络连接正常
- 打开浏览器开发者工具查看错误信息

### 2. 听不到 AI 声音

**症状**：能看到 AI 的文字回复，但听不到声音

**解决办法**：
- 检查电脑音量是否打开
- 检查浏览器是否静音
- 尝试刷新页面重新连接

### 3. AI 听不到你

**症状**：麦克风图标显示，但 AI 没有反应

**解决办法**：
- 确保已授予麦克风权限
- 检查系统麦克风设置
- 尝试更换浏览器（推荐Chrome/Edge）

### 4. 对话自动断开

**症状**：说一句话后连接就断开了

**解决办法**：
- 检查 API Key 配额是否用完
- 查看浏览器控制台的错误信息
- 确保使用的是最新版本的浏览器

## 📊 查看详细日志

1. 打开浏览器开发者工具（F12 或右键 → 检查）
2. 切换到 "Console" 标签
3. 可以看到详细的连接和响应日志
